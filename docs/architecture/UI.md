# Interface principles and implementation status
Reviewed [Linear navigation redesign](https://linear.app/now/how-we-redesigned-the-linear-ui), [Vercel Geist](https://vercel.com/geist/stack), [GitHub Primer](https://primer.github.io/), [Grafana Saga](https://grafana.com/developers/saga/) and [Carbon table accessibility](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/accessibility). Use restrained colors, compact contextual navigation, table captions, ordered event timelines, accessible labels and visible focus. No copied layouts or decorative generated assets.

The dependency-free TypeScript browser interface is the currently built host, served by FastAPI. It contains functional forms, genuine persisted metrics, trace evidence, review submission, paired comparisons, release policies and downloads. Next.js App Router host source reuses this interface. Next.js dependencies are unavailable offline, so the Next build and lockfile remain blocked. This fallback does **not** satisfy full React/Radix/TanStack Query/React Hook Form/Zod/Tailwind/Vitest acceptance. Native HTML forms and dialogs provide the fallback semantics; keyboard and visual behavior still require browser review. No claim of WCAG conformance is made.

The offline interface was typechecked with cached TypeScript 4.9.5, which supports its syntax. Next source uses a separate TypeScript version. System sans-serif and monospace avoid network font downloads. Light/dark tokens and responsive layouts are implemented; visual review is blocked by Chrome's denied socket calls. Playwright journeys and axe checks are provided for execution outside the restricted environment.
